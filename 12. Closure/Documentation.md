Q: What is Closure?

Closure is a function that remembers its lexical scope even after the outer function has finished execution.

🔥 Final Concept Summary

✔️ Function ke andar function ho
✔️ Inner function outer variable use kare
✔️ Outer function execute ho chuka ho
✔️ Phir bhi variable memory me ho

🧠 Ek Line Me

Closure allows a function to access variables from its outer scope even after the outer function has returned.
